#Keyless Entry Body Control Module (BCM)

This project simulates an automotive Body Control Module using Arduino.

## Features
- RFID-based keyless entry (RC522)
- Servo-controlled door lock
- Automatic climate control (fan relay)
- Headlight automation using LDR
- Ultrasonic parking assist with buzzer
- Finite State Machine (LOCKED / ACTIVE)

## Hardware Used
- Arduino Uno
- RC522 RFID Module
- Servo Motor
- HC-SR04 Ultrasonic Sensor
- Buzzer
- LDR
- Relay Module (for fan / load simulation)
- I2C LCD (16x2)

## Notes
This project was developed and tested in a desktop environment.
